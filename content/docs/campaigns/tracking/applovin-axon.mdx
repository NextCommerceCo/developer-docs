The starter templates include the AppLovin Axon pixel. Add your event key and the funnel reports page views, checkout steps and purchases to Axon from the shopper's browser.

The **AppLovin AXON** store app covers your NEXT storefront, not funnels.

## Before you start

- Your Axon event key, from your AppLovin account.
- A funnel that is ready for tracking. See [Set up tracking](/docs/campaigns/tracking/getting-started).

## Set up

1. In `_data/campaigns.json`, add your event key to your campaign:

```json title="_data/campaigns.json"
{
  "my-campaign": {
    "name": "My Campaign",
    "axon_event_key": "your-event-key"
  }
}
```

2. Build with `npm run build` and deploy.
3. Add the server function in [Keep Axon's cookie for a year](#keep-axons-cookie-for-a-year) below.

## What gets tracked

Page views, product views, add to cart, checkout started, payment details and purchases.

Each accepted upsell counts as another purchase, so an order with two upsells shows in Axon as three purchases.

## Shopper details

To send the shopper's email, phone and customer ID with each purchase, add this to your campaign:

```json
"axon_send_user_data": "true"
```

Turn it on only when your privacy policy covers it. See [Privacy and consent](/docs/campaigns/tracking#privacy-and-consent).

## Keep Axon's cookie for a year

Axon's pixel recognises a returning shopper with a cookie named `_axwrt`. Some browsers, including Safari, shorten the life of cookies that a script sets. AppLovin [strongly recommends](https://support.applovin.com/en/growth/promoting-your-websites/track-and-optimize/google-tag-manager) that your site's server sets the same value again as a one-year cookie named `axwrt`.

A starter template funnel is a static site, so this needs a small server function. On Netlify, add this one file. It runs on every page request, and when the shopper already has `_axwrt`, it adds `axwrt` to the response:

```js title="netlify/edge-functions/axwrt.js"
const ROOT_DOMAIN = 'example.com';

export default async (request, context) => {
  const response = await context.next();

  const cookies = request.headers.get('cookie') || '';
  const match = cookies.match(/(?:^|;\s*)_axwrt=([A-Za-z0-9._-]+)/);
  if (!match) return response;

  // Share the cookie across your subdomains. Leave Domain off on preview hosts.
  const host = new URL(request.url).hostname;
  const onRoot = host === ROOT_DOMAIN || host.endsWith(`.${ROOT_DOMAIN}`);
  const domain = onRoot ? `; Domain=.${ROOT_DOMAIN}` : '';

  response.headers.append(
    'Set-Cookie',
    `axwrt=${match[1]}${domain}; Path=/; Max-Age=31536000; SameSite=Lax; Secure`
  );
  return response;
};

export const config = {
  path: '/*',
  // Pages only, so the cookie is never attached to cached files.
  excludedPath: ['/*.css', '/*.js', '/*.json', '/*.png', '/*.jpg', '/*.jpeg', '/*.webp', '/*.svg', '/*.ico', '/*.woff2'],
};
```

Set `ROOT_DOMAIN` to your funnel's root domain, without `www`. There is nothing to add to your pages or to `netlify.toml`. The cookie is in place from the shopper's second page view.

Any server or edge platform can do the same thing; Netlify is the example.

## Verify it works

1. Open your funnel in a new private window and go through it.
2. Place an order with a [test card](/docs/testing) and continue to the next page.
3. In your AppLovin account, check that the events arrive, including the purchase.
4. Open a second funnel page, then check in your browser's developer tools that a cookie named `axwrt` is set.

More help is in [Test and troubleshoot tracking](/docs/campaigns/tracking/testing-and-troubleshooting).
